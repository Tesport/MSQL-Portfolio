# Конспект по MS SQL Server  

*Дата: 04.09.2026*

---

## 1. Иерархия SQL Server

| Уровень              | Что это такое                                                                 |
|----------------------|--------------------------------------------------------------------------------|
| Машина (хост)        | Физический или виртуальный компьютер, на котором установлена ОС               |
| Экземпляр SQL Server (Instance) | Отдельная установка SQL Server на машине, слушает определённый **порт** (по умолчанию `TCP 1433`); на одной машине может быть несколько экземпляров |
| База данных (Database) | Логический контейнер данных внутри экземпляра сервера                        |
| Таблица (Table)      | Структура для хранения данных (строки и столбцы) внутри базы данных            |

**Подключение к серверу** обычно указывается в виде `имя_машины\имя_экземпляра, порт` (например, `192.168.1.10\SQLEXPRESS,1433`) — то есть для подключения нужно знать адрес машины, порт и (если их несколько) имя нужного экземпляра.

Иерархия вложенности: **Машина → Экземпляр сервера → База данных → Таблица**.

---

## 2. Объекты базы данных  

- **Таблицы (Tables)** — хранят собственно данные в виде строк и столбцов.
- **Представления (Views)** — сохранённые SQL-запросы (выражения), которые возвращают набор данных в виде виртуальной таблицы; сами данные не хранят.
- **Хранимые процедуры (Stored Procedures)** — заранее скомпилированный код на T-SQL, который выполняется по запросу и может принимать параметры.
- **BLOB-поля** — поля для хранения больших двоичных данных (изображения, файлы, документы) внутри таблиц.
- **Иные метаданные** — индексы, ограничения (constraints), триггеры, схемы, пользователи и т.д.

## 3. Типы данных и их предназначение

### 3.1 Целочисленные типы (Integer)
Хранят целые числа без дробной части. Разница — в диапазоне значений и объёме памяти.

| Тип        | Диапазон                          | Память  |
|------------|-------------------------------------|---------|
| `tinyint`  | 0 … 255                            | 1 байт  |
| `smallint` | −32 768 … 32 767                   | 2 байта |
| `int`      | ≈ −2,1 млрд … 2,1 млрд              | 4 байта |
| `bigint`   | ≈ −9,2×10¹⁸ … 9,2×10¹⁸               | 8 байт  |

### 3.2 Дробные (приближённые и точные числовые) типы — **исправлено**
Изначально в конспекте сюда ошибочно попали `Bit`, `Text`, `Image`, `RowGUID`, `SQL_Variant` — это **не числовые/дробные типы**. Правильный список:

| Тип             | Предназначение                                                        |
|-----------------|------------------------------------------------------------------------|
| `decimal(p,s)` / `numeric(p,s)` | Точные дробные числа с фиксированным числом знаков после запятой (для денег, точных расчётов) |
| `float(n)`      | Приближённое число с плавающей точкой (для научных вычислений)         |
| `real`          | Аналог `float(24)`, приближённое число с плавающей точкой меньшей точности |

### 3.3 Дата и время
| Тип              | Предназначение                                                    |
|------------------|----------------------------------------------------------------------|
| `datetime`       | Дата и время с точностью до ~3.33 мс, диапазон с 1753 по 9999 год     |
| `smalldatetime`  | Дата и время с точностью до минуты, диапазон 1900–2079               |
| `date`           | Только дата (без времени)                                            |
| `time`           | Только время (без даты)                                              |
| `datetime2`      | Расширенная версия `datetime` с большей точностью и диапазоном       |
| `datetimeoffset` | Дата и время с учётом часового пояса                                 |

### 3.4 Денежные типы
| Тип           | Предназначение                                             |
|---------------|---------------------------------------------------------------|
| `money`       | Хранение финансовых данных с точностью до 4 знаков после запятой, ±922 трлн |
| `smallmoney`  | То же самое, но с меньшим диапазоном (±214 748.3647)          |

### 3.5 Символьные (строковые) типы
| Тип             | Предназначение                                                       |
|-----------------|---------------------------------------------------------------------|
| `char(n)`       | Строка фиксированной длины (не Unicode)                              |
| `varchar(n)`    | Строка переменной длины (не Unicode), экономит место                 |
| `nchar(n)`      | Строка фиксированной длины в Unicode (для многоязычных данных)       |
| `nvarchar(n)`   | Строка переменной длины в Unicode                                    |
| `text` / `ntext`| Устаревшие типы для больших текстов; рекомендуется `varchar(max)` / `nvarchar(max)` |

### 3.6 Прочие специальные типы (исправленная категория)
| Тип               | Предназначение                                                       |
|-------------------|-----------------------------------------------------------------------|
| `bit`             | Логический тип: 0, 1 или NULL (используется как булево значение)     |
| `image`           | Устаревший тип для хранения больших двоичных данных (заменён на `varbinary(max)`) |
| `varbinary(max)`  | Современный тип для BLOB-данных (файлы, изображения)                  |
| `uniqueidentifier`| Хранит GUID — глобально уникальный идентификатор (128 бит)            |
| `sql_variant`     | Может хранить значения разных типов данных в одном столбце            |

## 5. Расширения файлов MS SQL Server

| Расширение | Файл                          | Предназначение                                                             |
|------------|-------------------------------|-------------------------------------------------------------------------------|
| `.mdf`     | Primary Data File             | Основной файл данных базы — хранит сами данные и системные таблицы БД        |
| `.ndf`     | Secondary Data File           | Дополнительный (вторичный) файл данных; используется, когда данные БД разносят по нескольким файлам/дискам |
| `.ldf`     | Log File                      | Файл журнала транзакций — хранит информацию обо всех изменениях для восстановления БД |
| `.bak`     | Backup File                   | Полная резервная копия базы данных                                          |
| `.trn`     | Transaction Log Backup        | Резервная копия журнала транзакций                                          |
| `.sql`     | SQL Script File               | Текстовый файл со SQL-запросами/скриптами                                   |
| `.trc`     | Trace File                    | Файл трассировки (лог событий сервера, например из SQL Server Profiler)      |
| `.dtsx`    | SSIS Package                  | Пакет SQL Server Integration Services (ETL-процессы)                        |
| `.rdl`     | Report Definition             | Файл отчёта для SQL Server Reporting Services (SSRS)                        |

---

Отображаются в SQL Server Management Studio: `Databases → System Databases`.

| БД      | Назначение                                                            |
|---------|------------------------------------------------------------------------|
| `master`  | Хранит информацию обо всех базах данных сервера, конфигурацию сервера |
| `model`   | Шаблон, на основе которого создаётся каждая новая БД                 |
| `msdb`    | Используется SQL Server Agent для планирования заданий, оповещений и т.д. |
| `tempdb`  | Временное хранилище для промежуточных данных, временных таблиц, сортировок |
